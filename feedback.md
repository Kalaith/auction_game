# Project Review

## Project

**Name:** Auction House Tycoon

**One Sentence Pitch:** Particpate in auctions, acure a portfolio of houses, make alot of money


# 1. First Impression
Spend 10-20 minutes using the project without making changes.
- auctions are not fun at the start, all the stats point to the player not hitting reserve with the profitable bid, this is okay if there is things to improve it
- other bidders are happy to go alot of the initial target
- does feel like there is any strategy in auto bidding
- current ui looks very flat and uninspired

# 2. Story
Would I keep reading?
not a story based game, the story emergence is from those great wins and losses that happening during gameplay


# 3. Does it Have Potential?
Ignoring its current state...
Could this become something great with more work?
- Has potential, the auction system needs to be the draw

# 4. Biggest Problems
- the auction feels like your forced to go 100k over budget to afford anything

# 5. Best Parts
What already works well?
- there is some tension already watching the other bidders, which is a good sign for future playability

# 6. Next Goal
What is the **single most important milestone**?
- make auctions interesting, add more tension, make it worth going over budget in some cases, allow cheap sells sometimes.
- when the player bidds and how often, e.g. player rasies the price 30k instead of 10k alot of buyers are now hestinate to buy, or not.
